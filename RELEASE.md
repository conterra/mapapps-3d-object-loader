✅ Tested for map.apps 4.20.3 / Linie 4

#### Release Notes
- Initial release of the 3D Object Loader bundle `dn_3dobjectloader`:
  - Place prefabricated or uploaded glTF (`.glb`) models in a 3D scene, then move, rotate and scale them.
  - Seven prefabricated objects ship with the bundle; apps can add their own or replace them.
  - Optional planning area that hides an integrated mesh around the object.
  - Objects are stored in the browser (IndexedDB) and can be shared via the URL parameter `obj3d`.
  - Table of contents actions to zoom to, edit and delete objects.
